# 纯浮层与实时推荐设计

## 目标

应用只保留一个常驻浮层，不再创建设置页面、Dock 图标或状态栏图标。折叠态继续展示双周期用量，展开态展示用量、微信连接状态和推荐对话。由于应用没有其他入口，浮层只允许折叠，不允许隐藏；退出应用使用明确的退出按钮。

## 推荐刷新原则

Codex 的状态数据库或会话数据库发生写入后，监听器等待 2 秒合并连续写入，然后重新扫描候选会话。每 2 分钟的周期检查作为文件监听失效时的兜底，并同步更新用量。

候选范围是最近 14 天、未归档、非 Automation 的会话。失败、中断、长时间运行、等待用户回答、最后一条用户消息未获回复，以及今天有更新的正常会话都会进入候选。正在活跃执行且更新时间不足 20 分钟的会话不推荐。

摘要缓存使用最近四条用户/助手消息、任务状态、项目和分支信息计算内容哈希。哈希未变化时直接复用摘要，不消耗 Codex；哈希变化时立即批量重新摘要，不设置额外冷却时间。浮层在分析期间保留上一版推荐并显示“Codex 分析中”，完成后原位替换，同时展示最近扫描时间。

## 项目信息

优先读取 Codex `projects` 表中的项目名；没有显式项目时，从 Git remote 推导仓库名。推荐项展示项目名、Git 分支和会话更新时间，完整工作目录保留为悬停提示。没有项目的会话明确标为“独立对话”，并与项目会话采用相同的语义评分标准。微信提醒同样带项目名。

## 窗口与恢复

Tauri 仅配置 `usage` 窗口，并使用 macOS Accessory activation policy 隐藏 Dock 图标。再次从 Finder、Spotlight 或开机启动入口打开应用时，单实例处理器会显示现有浮层。微信登录失效时，二维码直接在展开浮层内展示。

## 验证

- 单元测试覆盖项目元数据解析、内容不变缓存和内容变化立即摘要。
- 使用真实 Codex SQLite 数据验证项目名和分支读取。
- 运行 TypeScript、React、Rust 全量检查。
- 重新打包调试版并检查系统中没有 Dock 图标、没有主窗口且浮层可正常折叠和展开。
