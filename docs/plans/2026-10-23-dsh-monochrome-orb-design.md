# DSH 灰阶 Orb 视觉设计

## 目标

保留现有 dsh-orb 式 hover、固定、收起和拖拽行为，将浮层从蓝绿色玻璃风格改为以白、浅灰和深灰为主的克制灰阶界面。小球继续展示双周期用量，但只使用不同明度的灰阶进度环。

## 视觉方向

- 外层面板：纯白背景，`#8a8a93` 细边，固定状态使用 `#5c5c66` 三像素外描边。
- 内容层级：用 `#f2f2f3`、`#e5e5e7` 和分割线表达层次，不使用彩色渐变或半透明玻璃。
- 文字：主文字接近黑色，辅助文字使用中灰；状态点也采用黑白灰。
- 小球：白色基底、深浅灰双进度环、深灰数字，折叠态使用 dsh-orb 同款柔和阴影。
- 控件：灰色圆形按钮和胶囊按钮，hover 仅改变灰度和边框，不引入强调色。

## 结构

展开面板保留现有信息能力，但弱化卡片嵌套：顶部为标题和窗口动作；中部为两列用量；下方使用单层浅灰列表承载推荐对话或微信连接状态。整体圆角和留白与 orb 保持一致。

## 动效与交互

视觉改造不改变现有状态机。继续使用 72px 小球、96px 原生窗口、300ms 展开/收起、180ms 离开延迟、4px 拖拽阈值以及 dsh-orb 的灰色 hover/pin 描边。

## 验证

- 检查 CSS 中不再残留蓝绿主题色和渐变背景。
- 运行浮层动效测试和桌面构建检查。
- 构建 release `.app`，截图验证折叠与展开状态的灰阶一致性和文字对比度。
