# Tahoe 蓝绿色浮层设计

## 目标

Codex 浮层采用接近 macOS Tahoe 小组件的蓝绿色视觉语言。展开态与紧凑胶囊态使用同一套渐变、边缘高光和层级，不改变现有布局和交互。

## 技术方案

不启用原生 Liquid Glass、vibrancy 或实时焦点染色。窗口缩放动画会频繁调整原生窗口尺寸，实时毛玻璃在这个过程中会增加合成开销并产生明显卡顿。

视觉完全由轻量 CSS 负责：

- 外层：蓝绿到浅蓝的稳定渐变、细亮边和单层阴影。
- 内层：同色系浅色表面，避免卡片层层套叠。
- 用量圆环：主周期使用青绿色，本周使用湖蓝色。
- 深色模式：使用更深的蓝绿染色和更克制的高光，避免发灰。
- 减少动态效果模式：保持现有动画降级策略。

## 组件层级

外层 `widget-shell` 和 `mini-widget` 使用不依赖后台采样的蓝绿色渐变。用量卡、推荐列表和连接面板作为浅色第二层表面，保持内容区分但不形成多层厚重卡片。圆环和按钮使用局部高光，避免增加额外合成负担。

## 状态与交互

视觉不随焦点变化，减少重绘和状态复杂度。折叠动画、拖动和点击热区保持不变。

## 验证

- TypeScript、React 和 Rust 全量检查通过。
- 构建 release `.app`，确认未启用原生窗口材质。
- 启动浮层并人工验证展开、收起过程流畅，蓝绿色风格在两种尺寸下保持一致。
