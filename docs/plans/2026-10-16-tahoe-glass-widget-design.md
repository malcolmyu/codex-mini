# Tahoe 毛玻璃浮层设计

## 目标

Codex 浮层采用接近 macOS Tahoe 小组件的真实环境毛玻璃。窗口失焦时呈现低饱和、偏中性的系统磨砂材质；获得焦点后，在同一材质上叠加蓝绿色染色、边缘高光和更清晰的层级。展开态与紧凑胶囊态使用同一套视觉语言，不改变现有布局和交互。

## 技术方案

原生窗口层使用 macOS vibrancy，而不是仅依赖 CSS `backdrop-filter`。Tauri 窗口继续保持透明、无边框，通过 Rust 在 `usage` 窗口上应用 `NSVisualEffectView` 材质，使桌面和其他窗口内容真正参与模糊。

前端监听 Tauri 窗口焦点变化，并在根节点切换聚焦状态 class。CSS 负责颜色、透明度、边缘高光和阴影：

- 失焦态：中性低饱和玻璃，较弱边缘高光，文字维持足够对比度。
- 聚焦态：叠加 Tahoe 蓝绿色半透明染色，提高内层卡片亮度和边缘层次。
- 深色模式：使用更深的蓝绿染色和更克制的高光，避免发灰。
- 减少动态效果模式：禁用不必要的过渡。

## 组件层级

外层 `widget-shell` 和 `mini-widget` 不再使用不透明实色背景，改为透明玻璃承载层。用量卡、推荐列表和连接面板作为第二层半透明表面，保持内容区分但不形成多层厚重卡片。圆环和按钮使用局部高光，避免破坏整体材质连续性。

## 状态与交互

窗口初始加载时读取当前焦点状态，之后订阅焦点变化。聚焦与失焦切换仅改变颜色、透明度和阴影，不改变尺寸与布局，因此不会干扰现有折叠动画、拖动和点击热区。

## 验证

- 单元测试覆盖焦点状态到根 class 的映射。
- TypeScript、React 和 Rust 全量检查通过。
- 构建 release `.app`，确认原生 vibrancy 能初始化。
- 启动浮层并验证聚焦、失焦两种状态；若当前机器缺少 GUI 自动化权限，则明确报告并保留人工观察入口。
